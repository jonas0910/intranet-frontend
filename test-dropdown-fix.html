🧪 Test Dropdown Fix

Esta página prueba que los dropdowns del navbar funcionen correctamente.

Instrucciones:
  1. Haz clic en el ícono de comentarios 🔽 - debería mostrar el dropdown de mensajes
  2. Haz clic en el ícono de notificaciones 🔔 - debería mostrar el dropdown de notificaciones
  3. Haz clic en "Usuario Demo" 🔽 - debería mostrar el menú de usuario
✅ Si funciona:
  • Los dropdowns se abren al hacer clic
  • Los dropdowns se cierran al hacer clic fuera
  • Un dropdown se cierra cuando abres otro
  • No hay errores en la consola del navegador
⚠️ Si no funciona:
  • Verifica que Bootstrap JS se está cargando
  • Verifica que jQuery está disponible
  • Revisa la consola del navegador por errores
  • Asegúrate de que los scripts se ejecuten después del DOM
