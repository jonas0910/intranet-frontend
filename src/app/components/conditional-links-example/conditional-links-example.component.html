Patrón de Enlaces Condicionales

✅ Usando *ngIf para manejar enlaces con y sin URL

{{ menu.nombre }} Activo {{ menu.nombre }} En desarrollo
Los enlaces con URL navegan, los sin URL muestran mensaje informativo
Comparación: Antes vs Después
❌ ANTES (Problemático): 
<a href="#" 
   class="nav-link" 
   (click)="navigateTo(menu.url); $event.preventDefault()">
  {{ menu.nombre }}
</a>

// ❌ Problemas:
// - href="#" innecesario
// - preventDefault() manual
// - Lógica de navegación mezclada
❌ Problemas: href="#", preventDefault(), lógica mezclada
✅ DESPUÉS (Correcto): 
<a *ngIf="menu.url; else noLink" 
   class="nav-link" 
   [routerLink]="menu.url">
  {{ menu.nombre }}
</a>

<ng-template #noLink>
  <a class="nav-link disabled" 
     href="javascript:void(0)">
    {{ menu.nombre }}
  </a>
</ng-template>
✅ Beneficios: routerLink nativo, semántica correcta, separación clara
Casos de Uso del Patrón
📋 Menús Dinámicos

Cuando los menús vienen de una API y algunos pueden no tener URL aún.

menu.url ? routerLink : disabled
🔐 Permisos de Usuario

Mostrar enlaces deshabilitados para usuarios sin permisos.

hasPermission ? routerLink : disabled
🚧 En Desarrollo

Mostrar funcionalidades próximas como deshabilitadas.

isReady ? routerLink : disabled
💡 Ventajas del Patrón:
  • Semántica clara: routerLink para navegación, disabled para no navegación
  • Accesibilidad: Los screen readers entienden el estado disabled
  • UX consistente: Comportamiento predecible para el usuario
  • Mantenible: Lógica separada y fácil de entender
Implementación Práctica
📝 Estructura de Datos Recomendada:
interface MenuItem {
  nombre: string;
  url?: string | null;        // ✅ Opcional - puede ser null/undefined
  icon?: string;
  activo?: boolean;
  permisos?: string[];
}
🔧 Template Angular:
<a *ngIf="menu.url; else noLink" 
   class="nav-link" 
   [routerLink]="menu.url"
   routerLinkActive="active">
  <i [class]="menu.icon" class="mr-2"></i>
  {{ menu.nombre }}
</a>

<ng-template #noLink>
  <a class="nav-link disabled" 
     href="javascript:void(0)"
     (click)="onDisabledAction(menu)">
    <i [class]="menu.icon" class="mr-2"></i>
    {{ menu.nombre }}
    <span class="badge badge-warning ml-2">Próximamente</span>
  </a>
</ng-template>
⚙️ Método en el Componente:
onDisabledAction(menu: MenuItem): void {
  // Mostrar mensaje informativo
  this.notificationService.info(
    `"${menu.nombre}" estará disponible próximamente`
  );
  
  // O registrar analytics
  this.analytics.track('disabled_menu_clicked', {
    menu: menu.nombre
  });
}
