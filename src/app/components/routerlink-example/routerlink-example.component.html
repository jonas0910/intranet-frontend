Comparación: Antes vs Después
❌ ANTES (Problemático): 
<a href="#" 
   class="dropdown-item" 
   (click)="navigate('/dashboard')">
  Dashboard
</a>

<a href="#" 
   class="dropdown-item" 
   (click)="exportData(); $event.preventDefault()">
  Exportar
</a>
❌ Problemas: href="#", preventDefault(), mezcla de responsabilidades
✅ DESPUÉS (Correcto): 
<a routerLink="/dashboard" 
   class="dropdown-item">
  Dashboard
</a>

<button class="dropdown-item" 
        (click)="exportData()">
  Exportar
</button>
✅ Beneficios: routerLink nativo, semántica correcta, mejor UX
Reglas Rápidas
✅ USA routerLink cuando:
  • Es navegación interna
  • Cambia de vista/página
  • Es breadcrumb funcional
  • Es menú principal
✅ USA button cuando:
  • No navega (ejecuta acción)
  • Es dropdown action
  • Es paginación funcional
  • Es toggle/un toggle
📖 Recuerda: La regla de oro es: Si el elemento navega → routerLink, si el elemento acciona → button.
